# Contributing to HI.

Thanks for your interest in contributing to HI. — the balance between humans and technology, measured.

## How to Contribute

### Report Issues
- Open a GitHub issue for bugs, data corrections, or feature requests
- Include the company name, ticker, and what looks wrong

### Data Corrections
- If a company's score seems off, open an issue with the correct data source
- We prioritize corrections backed by public, verifiable data

### Code
- Fork the repo, create a branch, submit a PR
- Follow existing code style
- Test locally before submitting

### Methodology Feedback
- The scoring methodology is open source — we welcome scrutiny
- Open a discussion for methodology questions or suggestions

## What We Don't Accept

- PRs that modify the scoring formula without discussion
- Contributions from companies attempting to influence their own score
- Anything that compromises the independence of HI Grades

## Code of Conduct

Be kind. Be human. That's the whole point.
